# samples/robot_face_animation.py の修正計画

`samples/robot_face_animation.py` を修正し、目を閉じるときの表現を、現在の上向きの曲線（山なり）だけでなく、下向きの曲線（谷なり）にも変更できるようにします。

## 計画の詳細

### 1. `FaceState`クラスへの属性追加

顔の状態を管理する`FaceState`クラスに、目が閉じているときの曲がり具合を制御するための新しい属性として `eye_curve` を追加します。

この`eye_curve`の値によって、以下のように目の形が変わるようにします。

*   **正の値:** 上向きの曲線 (山なり、例: 笑顔)
*   **負の値:** 下向きの曲線 (谷なり、例: 悲しい顔)
*   **`0`:** 直線

### 2. `MOODS`定義の更新

`RobotFace`クラスで定義されている様々な表情（`MOODS`）に、この`eye_curve`属性を追加します。例えば、`sad`（悲しい）の表情では`eye_curve`に負の値を設定します。

### 3. 描画ロジックの修正

目の描画を担当する`_draw_eye`メソッドを修正します。目が閉じている場合の描画ロジックを、`eye_curve`の値に応じて以下のように分岐させます。

*   `eye_curve`が正の場合、山なりのベジェ曲線を描画します。
*   `eye_curve`が負の場合、谷なりのベジェ曲線を描画します。
*   `eye_curve`が`0`の場合、直線を描画します。

### 4. 状態更新ロジックの修正

表情が滑らかに変化するように、`RobotFace`クラスの`update`メソッドに`eye_curve`属性の線形補間処理を追加します。

## 影響範囲

この変更は、`wink_left`や`wink_right`といった目の開き具合を制御する機能には影響を与えません。これらの属性は引き続き目の開閉を制御し、目が閉じている際の形状を`eye_curve`が決定するという役割分担になります。
