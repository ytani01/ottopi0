# Plan02: `EyeState` クラスの再リファクタリング計画

## 1. はじめに

`Plan01.md`へのフィードバックと、新たな設計方針をいただき、ありがとうございます。
いただいた方針に基づき、`EyeState`クラスのリファクタリング計画を再検討しました。

本計画では、`MOODS`での表情定義をより直感的かつ簡潔にすることを目指しつつ、既存の滑らかなアニメーションロジックは維持します。

## 2. 新たな設計方針

ユーザーから提示された、以下の新しい設計方針に基づいてリファクタリングを行います。

1.  **目標状態の定義を簡潔に**:
    `MOODS`で目の状態を定義する際の記述を、よりシンプルにします。
2.  **アニメーションロジックの維持**:
    `openness` と `curve` を独立して線形補間する、既存のアニメーションの仕組みは変更しません。これらはアニメーションの中間状態を表現するために引き続き内部的に使用されます。
3.  **目標状態の制約**:
    - 目が閉じる目標状態は `curve` が `0` でない (`-1` or `1`) 場合のみとします。
    - 「閉じた直線 (`openness=0`, `curve=0`)」の目は、目標状態から除外します。
    - `curve` の目標値が `0` の場合は、`openness` の目標値は必ず `1.0`（開いた目）となります。
4.  **既存の表情の維持**:
    新たに追加された `kiss` を含め、現在定義されているすべての `MOODS` を表現可能とします。

## 3. リファクタリング計画

上記の方針を実現するため、`EyeState` クラスの初期化（`__init__`）方法を変更し、目標状態の定義方法を簡潔にします。

### 3.1. `EyeState` クラスの改造

- Pythonのデコレータ `@dataclass` の使用をやめ、通常のクラスとして再定義します。これにより、`__init__` メソッドを柔軟にカスタム実装できます。
- 新しい `__init__` メソッドは、引数として `size` と、オプションの `closed_curve` を受け取ります。
- `__init__` メソッド内で、`closed_curve` 引数の有無と値に応じて、アニメーション用の `self.openness` と `self.curve` の初期値を設定します。
    - `closed_curve` が指定され、かつ `0` でない場合：
      閉じた目と判断し、`self.openness = 0.0` と `self.curve = closed_curve` を設定します。
    - `closed_curve` が指定されない、または `0` の場合：
      開いた目と判断し、`self.openness = 1.0` と `self.curve = 0.0` を設定します。
- この変更に合わせて、`copy()` メソッドもカスタム実装します。

#### **修正後の `EyeState` コード案**

```python
from typing import Optional

# @dataclass を削除
class EyeState:
    """Eye status."""

    # __init__で初期化するため、ここでは型アノテーションのみ
    openness: float
    size: float
    curve: float

    def __init__(self, size: float = 8.0, closed_curve: Optional[float] = None):
        """
        Constructor.
        'closed_curve' に値が設定された場合、目は閉じていると判断する。
        """
        self.size = size
        if closed_curve is not None and closed_curve != 0:
            # 閉じた目（カーブあり）
            self.openness = 0.0
            self.curve = closed_curve
        else:
            # 開いた目
            self.openness = 1.0
            self.curve = 0.0

    def copy(self):
        """
        アニメーション中の状態も含めて正確にコピーする
        """
        new_state = EyeState(size=self.size)
        new_state.openness = self.openness
        new_state.curve = self.curve
        return new_state

    def __repr__(self):
        """
        デバッグ用に現在の内部状態を表示する
        """
        return (f"EyeState(size={self.size}, openness={self.openness:.2f}, "
                f"curve={self.curve:.2f})")
```
※ `from typing import Optional` をファイルの先頭に追加する必要があります。

### 3.2. `FaceState` クラスの修正

`EyeState`の`__init__`が変更されたため、`FaceState`の`left_eye`と`right_eye`の`default_factory`も修正します。

#### **修正後の `FaceState` コード案**
```python
@dataclass
class FaceState:
    # ... (他のフィールドは変更なし)
    left_eye: EyeState = field(default_factory=lambda: EyeState())
    right_eye: EyeState = field(default_factory=lambda: EyeState())
    # ...
```

### 3.3. `RobotFace.MOODS` の更新

`EyeState`の新しい初期化方法に合わせて、`MOODS`の定義をよりシンプルに更新します。

#### **`MOODS`の更新例**

- **wink-r**:
  - 変更前: `left_eye=EyeState(openness=0, curve=1)`
  - 変更後: `left_eye=EyeState(closed_curve=1)`
- **sleepy**:
  - 変更前: `left_eye=EyeState(openness=0, curve=-1)`
  - 変更後: `left_eye=EyeState(closed_curve=-1)`
- **neutral** (目が開いている表情):
  - 変更前: `left_eye=EyeState()`
  - 変更後: `left_eye=EyeState()` (変更なし)

## 4. 影響範囲と互換性

- **アニメーションロジック**: `RobotFace.update()` は、引き続き `openness` と `curve` 属性を直接補間するため、変更は不要です。
- **描画ロジック**: `_draw_eye()` も、`openness` と `curve` 属性を直接参照するため、変更は不要です。
- **互換性**: この変更は `samples/robot_face_animation.py` ファイル内で完結し、他のファイルへの影響はありません。

## 5. 結論

このリファクタリング計画により、`MOODS`定義の可読性と直感性を向上させつつ、既存の滑らかなアニメーション表現を完全に維持できます。これはユーザーから提示された新たな要件をすべて満たすものと考えます。
