# テストスイート改善計画 (Plan01.md)

`tests/` ディレクトリ内の既存のテストプログラムをレビューした結果、以下の改善点を特定しました。

## 1. モッキング手法の統一

現在、一部のテストファイルでは `unittest.mock.patch` を直接使用しており、セットアップ/ティアダウンの手動管理やコンテキストマネージャの使用が必要です。これを `pytest-mock` プラグインが提供する `mocker` フィクスチャを使用するように統一することで、コードを簡潔にし、可読性と保守性を向上させます。

**対象ファイル:**
- `tests/test_04_svr.py`
- `tests/test_05_bt.py`
- `tests/test_06_cmd.py`
- `tests/test_07_webui.py`

**改善内容:**
- `unittest.mock.patch` の使用箇所を `mocker.patch` に置き換える。
- `patcher.start()` / `stop()` の手動管理を削除する。
- `patch` コンテキストマネージャを `mocker` フィクスチャの呼び出しに置き換える。

## 2. テストクラス名の命名規則の統一

最近のリファクタリング（サブコマンド名の変更など）に伴い、ファイル名は変更されましたが、テストクラス名が古い命名規則のまま残っている箇所があります。これを新しいファイル名やモジュール名に合わせたクラス名に変更します。

**対象と変更案:**
- `tests/test_04_svr.py`: `TestJrpcsvr` -> `TestSvr`
- `tests/test_05_bt.py`: `TestJrpcClntBt` -> `TestBt`
- `tests/test_06_cmd.py`: `TestJrpcClntCli` -> `TestCmd`

## 3. 実行計画

1.  上記の各ファイルに対して、モッキングのリファクタリングとクラス名の変更を実施します。
2.  変更後、全テストを実行し (`mise run test`)、リファクタリングによって機能が壊れていないことを確認します。
