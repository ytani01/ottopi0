# OttoPi0 Code Style and Conventions

- **Formatting:** `ruff` is used for code formatting. The configuration is in `pyproject.toml`.
- **Linting:** `ruff` is used for linting. The configuration is in `pyproject.toml`.
- **Static Type Checking:** `mypy` and `pyright` are used for static type checking. The configuration is in `pyproject.toml`.
- **Docstrings:** Docstrings are used and their line length is enforced by `ruff`.
