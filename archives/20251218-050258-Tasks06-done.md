# 総合リファクタリングタスク (Tasks06.md)

`Plan06.md`で定義されたリファクタリング計画を、以下の具体的な作業手順に分解します。

---

### 1. 定数の一元管理 (計画1)

- [x] `RobotFace`クラスに、レイアウト座標を管理する`LAYOUT`クラス変数を定義する。
- [x] `RobotFace`クラスに、描画色を管理する`COLORS`クラス変数を定義する。
- [x] 描画関連メソッド (`draw`, `_draw_eye`) 内のハードコードされた数値と色を、新しく定義した`LAYOUT`と`COLORS`を参照するように置き換える。

### 2. 描画メソッドの責務分離 (計画2)

- [x] `_draw_eye`メソッドから眉毛の描画ロジックを分離し、`_draw_brows`メソッドとして独立させる。
- [x] `draw`メソッドから輪郭の描画ロジックを分離し、`_draw_outline`メソッドとして独立させる。
- [x] `draw`メソッドから口の描画ロジックを分離し、`_draw_mouth`メソッドとして独立させる。
- [x] `draw`メソッドから両目の描画ロジックを分離し、`_draw_eyes`メソッドとして独立させる。
- [x] `draw`メソッドの本体を、新しく作成した各描画メソッドの呼び出しに再構築する。

### 3. 自律動作ロジックの分離 (計画3)

- [x] `RobotFace`クラスから`animate_step`メソッドと、関連するタイマー変数 (`_next_mood_time`, `_next_gaze_time`) を削除する。
- [x] `RobotFaceApp`クラスに、自律動作のロジックとタイマー変数を移管する。`main`メソッドのループ内で表情や視線をランダムに変更する処理を実装する。

### 4. 品質確認

- [x] すべての変更完了後、`mise run lint` を実行して、コードスタイルと型チェックに問題がないことを確認する。
