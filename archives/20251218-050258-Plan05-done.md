# ベジェ曲線描画処理のメソッド化計画 (Plan05.md)

## 1. 目的

`samples/robot_face_animation.py`の`RobotFace`クラス内で、目と口の描画処理において重複している「ベジェ曲線の計算と描画」ロジックを抽出し、独立したプライベートメソッドとして共通化する。

これにより、コードのDRY (Don't Repeat Yourself) 原則を適用し、可読性と保守性を向上させる。

## 2. 背景

現状の実装では、`_draw_eye`メソッド（目が閉じている場合）と`draw`メソッド（口の描画）の両方で、3つの制御点からベジェ曲線を構成する多数の点を計算し、線として描画する、ほぼ同じコードブロックが存在する。

これらの重複したコードは、将来的な仕様変更（例: 曲線の計算方法の改善）の際に、複数の箇所を修正する必要があり、メンテナンスコストの増大や修正漏れのリスクにつながる。

## 3. 改善計画

### 計画1: `_draw_bezier_curve` メソッドの新規作成

`RobotFace`クラスに、ベジェ曲線の描画を専門に行う新しいプライベートメソッド `_draw_bezier_curve` を作成する。このメソッドは以下の引数を取る。

*   `draw`: `ImageDraw.Draw` オブジェクト
*   `p0`, `p1`, `p2`: 曲線を定義する3つの制御点の座標タプル `(x, y)`
*   `color`: 描画色
*   `width`: 線の太さ
*   `steps`: 曲線の滑らかさを決める分割数

メソッド内部では、指定されたステップ数でループを回し、2次ベジェ曲線の公式を用いて各点の座標を計算し、最後に`draw.line()`で曲線を描画する。

### 計画2: `_draw_eye` メソッドのリファクタリング

`_draw_eye`メソッド内の、目が閉じている場合のベジェ曲線描画ロジック（forループを含むブロック全体）を、新しく作成した `_draw_bezier_curve` メソッドの呼び出しに置き換える。

### 計画3: `draw` メソッドのリファクタリング

`draw`メソッド内の、口の描画部分にあるベジェ曲線描画ロジック（forループを含むブロック全体）を、同様に `_draw_bezier_curve` メソッドの呼び出しに置き換える。

---

この計画を実行することで、ベジェ曲線の描画ロジックが一箇所に集約され、コードの重複が排除される。これにより、`_draw_eye` と `draw` メソッドはよりシンプルになり、プログラム全体の構造が明確になることが期待される。
